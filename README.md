# Learning-hub
A website that tries to focus on the free and easy to access educational material.
Inspired from the idea of FreeCodeCamp and many others.
It is open-source so anyone can access its source code, except the videos that will soon be open-sourced after contribution.


# Contributions
Anyone from any field who even does not know web development can contribute on this open-source project by
providing video lectures on their line of work.
If you are from a programming field that does not have knowledge on web development can also contribute as a tutor.
Web developer can help in all sorts of way they like, include changes of web design , if everyone agrees, and can even help enhance the backend that is currently holded by a single json file.
